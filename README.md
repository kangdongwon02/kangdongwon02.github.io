# Dongwon Kang - academic homepage draft

A lightweight, accessible one-page academic profile intended for GitHub Pages.

## Preview locally

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Before publishing

- Create the public repository `kangdongwon02.github.io`.
- Confirm permission to publish paper titles and manuscript status with co-authors and institutions.
- Add DOI, IEEE Xplore, arXiv, code, slides, and poster links only when they exist.
- Add a public CV only after removing the phone number and any non-public details.
- Reconfirm Samsung, WCISL, ETRI, and patent wording for public disclosure.

## GitHub Pages

Place these files at the root of the public repository `kangdongwon02.github.io`, commit to the `main` branch, and enable Pages from the repository settings if it is not enabled automatically. The resulting URL will be <https://kangdongwon02.github.io/>.
